# Personal Portfolio / Resume Site

## Overview

This repository contains a static, responsive resume and portfolio website built with Bootstrap and common front-end libraries to show case my experience, projects, and skills.

## Project Structure

- `index.html` — Main homepage.
- `portfolio-details.html`, `service-details.html`, `starter-page.html` — Additional pages and examples.
- `assets/` — CSS, JavaScript, images, vendor libraries and third-party assets.
  - `assets/css/main.css` — Project stylesheet.
  - `assets/js/main.js` — Site scripts.
  - `assets/vendor/` — Third-party libraries (Bootstrap, AOS, Glightbox, Swiper, etc.).
- `forms/contact.php` — Example server-side contact form handler (PHP).
